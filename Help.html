SmartCalculator User Manual v3.0.0

Welcome to SmartCalculator, a premium high-fidelity scientific calculator built using WPF and .NET 8. This document describes the primary capabilities, modes of operation, user settings, and keyboard shortcuts.

1. Overview of Key Features

  • 130 Unique Visual Themes: Cycle themes using the ◉ button or hold it down to select from the on-screen list.
  • 20 Independent Ergonomic Skins: Cycle key designs using 🔲, hold it for the list, or choose MODE → ▶ → 5:SKIN. Skins change key shapes, 3D bevels, and Dpad navigation with zero label clipping.
  • Complete Compact Mode: Switch to the uniform 4×6 mini-calculator using Ctrl+M, the header toggle, or MODE → ▶ → 6:COMPACT. Features full arithmetic, parentheses, square root, percent, and fraction toggle.
  • Balanced Header with Developer Signature: Features developer Ahmad Ibrahim's Arabic calligraphy signature ("أحمد إبراهيم") prominently in the center (>300% enlarged vector cutout with transparent background), branding with persistent subtitle "Scientific Display • by: Ahmad Ibrahim" on the left, and window management / quick tools on the right.
  • Fixed Classic LCD: Themes and skins do not recolor the scientific display.
  • Tactile Dpad Feedback: The navigation shape, border, and depth follow the selected skin and respond to mouse or keyboard input.
  • Casio-style ERROR screen: If a formula is invalid, a dedicated error screen displays guidance. Press arrow keys to return to the edit screen at the cursor.
  • Memory & Angle Units: Fully persistent Ans/Memory and degrees/radians selector.

2. Modes of Operation (MODE / SETUP)

Press the MODE key to open the Mode menu. Select the mode by pressing the corresponding number:

Mode Select Key Description
COMP 1 Standard general arithmetic calculations (with integrals/derivatives).
CMPLX 2 Complex number calculations using imaginary i.
STAT 3 Single-variable statistical calculations and distribution functions.
BASE-N 4 Binary, Octal, Decimal, and Hexadecimal conversion and logic arithmetic.
MATRIX 5 Matrix dimensions definition and algebraic matrix equations.
VECTOR 6 Vector arithmetic (cross products, dot products).
TABLE 7 Function generation table for f(x).
SOLVE 8 Equation solver utilizing numerical approximations.

4. Troubleshooting Errors

When an error occurs, the calculator will display a specialized Casio-style screen:

  • Syntax ERROR: Appears when a formula is written incorrectly. Use the left/right arrow keys to dismiss the error and place the cursor exactly at the edit line to fix it, or press AC to clear.
  • Math ERROR: Appears for mathematical impossibilities (like dividing by zero). Press AC to clear the error.
